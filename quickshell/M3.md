# Material Design 3 в оболочке

Скилл: `skills/material-3`. Здесь — как его токены применимы к QML/Quickshell
и что именно считается «правильным» в этой оболочке.

## Токены (singletons/Theme.qml)

### Цвет
Схема строится из pywal: акцент → primary/secondary/tertiary, фон обоев →
нейтральные поверхности. Роли MD3 — **только** через `Theme.*`:

| Роль | Свойство | Где используется |
|------|----------|------------------|
| primary | `Theme.primary` | активные элементы, fill слайдера, акцентные иконки |
| on-primary | `Theme.scheme.onPrimary` | текст/иконки на primary |
| primary-container | `Theme.primaryContainer` | заметные контейнеры (кнопки-плитки, круги) |
| on-primary-container | `Theme.scheme.onPrimaryContainer` | текст на primary-container |
| secondary-container | `Theme.secondaryContainer` | выбранные плитки, tonal-кнопки |
| on-secondary-container | `Theme.scheme.onSecondaryContainer` | текст на secondary-container |
| error / error-container | `Theme.error`, `Theme.errorContainer` | ошибки, удаление, низкий заряд |
| surface | `Theme.surface` | базовая поверхность |
| on-surface | `Theme.scheme.onSurface` | основной текст |
| on-surface-variant | `Theme.scheme.onSurfaceVariant` | вторичный текст, неактивные иконки |
| surface-container-lowest/low/default/high/highest | `Theme.surfaceContainer*` | уровни тональной поверхности |
| outline | `Theme.outline` | важные границы (поля ввода) |
| outline-variant | `Theme.outlineVariant` | разделители, декоративные обводки |
| inverse-surface / inverse-on-surface | `Theme.inverseSurface`, `Theme.scheme.inverseOnSurface` | снекбары, подсказки |

**Внимание:** QML резервирует префикс `on` для обработчиков сигналов, поэтому
плоских `Theme.onSurface` нет — только `Theme.scheme.onSurface` и т.д.

Полупрозрачные поверхности (оболочка над обоями): `Theme.barSurface`,
`Theme.panelSurface`, `Theme.sheetSurface`, `Theme.menuSurfaceSolid`.
Слой состояния: `Theme.stateLayer(color, Theme.stateHover|stateFocus|statePressed)`.

### Типографика
`Text { font: Theme.typeBodyMedium }` — готовые font-значения:
`typeDisplayLarge…typeLabelSmall`. Числа — `Theme.typescale.titleMedium.size`.

Шкала: display 57/45/36, headline 32/28/24, title 22/16/14, body 16/14/12,
label 14/12/11. Не задавать `font.pixelSize` вручную.

### Формы
`Theme.shape.xs (4)`, `sm (8)`, `md (12)`, `lg (16)`, `xl (28)`, `full (999)`.

- кнопки, чипы, пилюли, индикаторы — `shape.full`;
- карточки, баннеры, поля — `shape.md`; маленькие поля — `shape.xs`;
- листы, диалоги, попапы, крупные плитки — `shape.xl`;
- разделители — без радиуса.

### Отступы
`Theme.space.xs 4`, `sm 8`, `md 12`, `lg 16`, `xl 24`, `xxl 32`. Внутренние
отступы компонентов — кратные 4.

### Иконки и тач-цели
`Theme.iconSize.sm 16 / md 20 / lg 24`; кнопка-иконка — `Theme.iconButtonSize`
(40), обычная кнопка — `Theme.buttonHeight` (40), список — `Theme.listItemHeight`
(56), шапка — `Theme.appBarHeight` (56), тач-минимум — `Theme.touchTarget` (48).

### Движение
`Theme.motionShort3/4`, `motionMedium1/2`, `motionLong1/2`;
кривые `curveEmphasized`, `curveEmphasizedDecelerate/Accelerate`,
`curveStandard`, `curveStandardDecelerate/Accelerate`.
Для `Behavior` использовать `MotionNumber { duration: …; curve: … }`.

## Правила

1. **Никаких магических значений.** Цвет — только роль; радиус — только
   `Theme.shape.*`; размер шрифта — только `Theme.type*`; отступ — `Theme.space.*`.
2. **Не менять поведение.** Правки только визуальные: `color`, `radius`,
   `font`, `border`, размеры/отступы, `Behavior`. Логику, биндинги, сигналы,
   `required property` и тексты не трогать.
3. **Не ломать биндинги.** В обработчиках — `Qt.binding()`, не `width = 10`.
4. **Тональная глубина вместо теней.** MD3 не использует тени по умолчанию:
   уровень — это `surface-container-*` или `Theme.stateLayer(...)`.
5. **Не смешивать MD2/MD3.** Никаких «просто скруглённых прямоугольников»
   с произвольным радиусом и теней — только токены.
6. **Текст на паре ролей.** `on-primary` только на `primary`,
   `on-secondary-container` только на `secondary-container` и т.п.
7. **Комментарии — по-русски**, как в проекте. Не удалять существующие
   пояснения, если правка их не отменяет.

## Состояния

- hover: `Theme.stateLayer(Theme.scheme.onSurface, Theme.stateHover)` поверх
  контейнера (отдельный `Rectangle` с `opacity` или цвет с альфой);
- pressed: `Theme.statePressed`; focus: `Theme.stateFocus`;
- disabled: контент `Theme.disabledContent`, контейнер `Theme.disabledContainer`;
- выбранное: `secondary-container` + `on-secondary-container`.

## Компоненты

- **Кнопки/иконки**: круглые 40×40 (`shape.full`), глиф `iconSize.md`;
  primary для главного действия, tonal — для второстепенного.
- **Списки**: строка 56, левая иконка 20–24, заголовок `titleSmall`/`bodyLarge`,
  поддержка `bodyMedium` цветом `onSurfaceVariant`; разделитель `outlineVariant`
  толщиной 1 с отступом 16.
- **Слайдер**: дорожка 4, активная часть `primary`, неактивная
  `surfaceContainerHighest`, ручка 4×24 `primary`.
- **Переключатель**: дорожка 52×32, выключен — `surfaceContainerHighest` +
  обводка `outline`, включён — `primary`.
- **Поля ввода**: контейнер `surfaceContainerHighest`, радиус `shape.xs`,
  обводка `outline` (focus — `primary` толщиной 2), подпись `bodySmall`.
- **Карточки**: `surfaceContainerHigh`, радиус `shape.md` (крупные — `xl`),
  без тени.
- **Диалоги**: `surfaceContainerHigh`, радиус `shape.xl`, заголовок
  `headlineSmall`, текст `bodyMedium`, кнопки — текстовые/залитые пилюли.
- **Снекбар**: `inverseSurface`, `onInverseSurface`, радиус `shape.xs`.
